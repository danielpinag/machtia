# MachtIA — framework repo

This repo holds the MachtIA learning framework itself: the rules
([MACHTIA.md](MACHTIA.md)), the developer profile (`LEVEL.md`, personal and
git-ignored — each developer creates theirs from
[LEVEL_TEMPLATE.md](LEVEL_TEMPLATE.md)), and the skills under `skills/`
(symlinked into `~/.claude/skills/`).

## Learning Mode — MachtIA

@MACHTIA.md

Learning goals for this project: AI-assisted development workflows,
Claude Code configuration (skills, imports, memory).

## Conventions

- LEVEL.md's Evidence log and History are **append-only**; the Skill map and
  Promotion tracker are the only sections edited in place.
- Changes to the rules in MACHTIA.md affect every connected project — discuss
  them with the developer before editing.
