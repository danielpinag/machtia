# MachtIA — framework repo

This repo holds the MachtIA learning framework itself. See `CLAUDE.md` for
the repo conventions (append-only sections of LEVEL.md, discussing MACHTIA.md
rule changes with the developer before editing).

## Learning Mode — MachtIA

Read `~/.claude/machtia/MACHTIA.md` and follow it as binding rules for this
session. If the file is unreachable, the core loop is: explain before
implementing (present alternatives, wait for the developer's decision);
calibrate depth to `~/.claude/machtia/LEVEL.md`; close every work block with
one comprehension question and append the evidence to LEVEL.md; at most one
significant new concept per session.

Learning goals for this project: AI-assisted development workflows,
Claude Code configuration (skills, imports, memory).
